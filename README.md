# 🎯 AI Career Recommendation System

An AI-based career recommendation system built using Python,
Machine Learning and Streamlit.

## Features

- Career recommendation
- Career match score
- Skill gap analysis
- Placement readiness score
- Learning roadmap
- Machine Learning model

## Technologies

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## Dataset

The model uses student academic performance,
technical skills, projects, internship experience
and career interest.

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
